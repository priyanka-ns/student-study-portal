# Student Study Portal

> **Academic group project write-up.** This repository documents a college project. It is a project overview, not a source-code repository.

A web-based portal that brings common study tools together in one place, so students can register, log in, and access study-related services through a single personalised interface instead of visiting many different websites.

## Tech Stack
- **Framework:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite (Django ORM)
- **Auth:** Django's built-in authentication (register / login with password validation)

*(Runs locally on Django's development server at `127.0.0.1:8000`.)*

## Modules
- **Login / Register** — account creation and access control for the portal.
- **Profile** — students review their activities and pending tasks.
- **Notes** — quick notepad for memos and short/long text notes, stored until deleted.
- **To-Do** — maintain daily schedules; add and remove items as they are finished.
- **Homework** — add homework with subject, title, description, due date and status; delete when completed.
- **YouTube** — search and play videos inside the portal.
- **Books** — browse a list of e-books available online.
- **Dictionary** — meaning, pronunciation and synonyms of a word.
- **Wikipedia** — search Wikipedia for quick information.
- **Conversion** — unit converter (length, mass, etc. — e.g. kilogram to pound, foot to yard).
- **Conversation** — start/join a group chat by room name and username.

## Purpose
Provide a single, globally accessible, 24x7, user-friendly and secure place for students to handle study activities — saving time and improving access to resources.
